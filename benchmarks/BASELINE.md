# GraphKV Ingest Benchmark Baseline

## Scope

These are actual measured timings from the current workstation, not estimated numbers. The baseline now has two parts:

- real checked-in SCIP corpora emitted by the official `@sourcegraph/scip-python@0.6.6` indexer from Python files that already live in this repository
- a synthetic scaling study from `benchmarks/generate_synthetic_scip.py` that still helps expose linearity across much larger payload sizes

The real corpora are the primary reference point for day-to-day regressions because they are protocol-valid, reproducible, and generated through an official indexer instead of hand-built wire bytes.

## Checked-In Real Corpora

- `benchmarks/data/python_send_scip_ws.scip`: official SCIP output for `tools/send_scip_ws.py`
- `benchmarks/data/python_repo.scip`: official SCIP output for all Python files currently present in this repository

Both files are regenerated by `benchmarks/generate_real_corpora.sh`, which pins `@sourcegraph/scip-python@0.6.6` and fixes the project metadata to keep the emitted SCIP stable.

The automated recorder script writes the latest generated report to `benchmarks/results/latest.md`. That file is a local generated artifact, while this `BASELINE.md` file remains the curated checked-in reference.

## Docker End-To-End Profile

The Docker profile exercises the production image build, in-container Warden serialization/compression profiling, Zstd SCIP WebSocket ingest, Zstd document NDJSON ingest, OpenCode synthesis, document retrieval marker validation, and concurrent binary ingest pressure.

Latest local command:


```sh

  -DGRAPHIFY_BUILD_SERVER=OFF \
  -DGRAPHIFY_REQUIRE_STD_PRINT=OFF \
  -DGRAPHIFY_BUILD_TESTS=OFF \
  -DGRAPHIFY_ENABLE_PROTOBUF_COMPAT=OFF \
  -DGRAPHIFY_BUILD_TOOLS=OFF

benchmarks/generate_real_corpora.sh

for fixture in benchmarks/data/python_send_scip_ws.scip benchmarks/data/python_repo.scip; do
  for run in 1 2 3 4 5; do
    ./build-benchmark/ingest_latency_benchmark "$fixture"
  done
done

python3 benchmarks/generate_synthetic_scip.py /tmp/index-1000.scip --documents 1000
python3 benchmarks/generate_synthetic_scip.py /tmp/index-10000.scip --documents 10000
python3 benchmarks/generate_synthetic_scip.py /tmp/index-100000.scip --documents 100000

./build-benchmark/ingest_latency_benchmark /tmp/index-10000.scip
./build-benchmark/ingest_latency_benchmark /tmp/index-100000.scip
```

## Readout

- The checked-in real corpora are now the default regression anchors, not the synthetic payloads.
- The single-script real corpus stays at 13.40 us mean-of-means with only 0.06 us run-to-run standard deviation.
- The full repo Python corpus stays at 59.58 us mean-of-means with 0.26 us run-to-run standard deviation and a worst observed P99 of 72.20 us.
- The synthetic study still matters because it shows the ingest path scaling close to linearly across roughly two orders of magnitude of input size.
